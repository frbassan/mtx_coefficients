# Matrix Coefficient Scripts

This folder contains two Python scripts for generating and extracting temperature and strain coefficients from FEBUS CSV data:

1. `mtx_coeff_gen.py` generates a simulated measurement from the 20 C input file.
2. `mtx_coeff_extract.py` compares the 20 C data with either a simulated file or an original 40 C file and calculates the coefficients.

The scripts are configuration-driven. They do not accept command-line arguments; edit the variables near the top of each script before running it.

## Requirements

- Python 3.9 or newer
- NumPy
- Matplotlib

Install the dependencies with:

```powershell
python -m pip install numpy matplotlib
```

## Input CSV files

The raw FEBUS files are expected to be in the same folder as the scripts:

- `t_20.csv`: baseline measurement at `T0 = 20 C`.
- `t_40.csv`: original measurement at the higher temperature, used when validation is disabled.

The raw files use semicolons as separators. Their optional `Param;...` metadata lines are skipped, and the `freqStep` metadata value is read when it is present. If `freqStep` is not found, the scripts use `-1.953125` as the default frequency step.

The scripts assume:

- One data row represents one spatial sample.
- The spatial resolution is `0.1` meter per sample.
- The Rayleigh peak is searched around frequency bin `100`, using a window of `10` bins.
- The Brillouin peak is the largest value outside that Rayleigh search window.

## 1. Generate simulated data

### Purpose

`mtx_coeff_gen.py` reads `t_20.csv`, applies the configured temperature change only to two analysis segments, and writes a simplified peak-data CSV for the simulated measurement.

### Configure

At the top of `mtx_coeff_gen.py`, review or change:

```python
file_path_T20 = 't_20.csv'
spatial_resolution = 0.1
seg_free = (1000.0, 1100.0)
seg_met = (1500.0, 1600.0)
dT = 40.0
```

`dT` is the temperature increase from the 20 C baseline. With the default `dT = 40.0`, the generated file name is `sim_t_60.csv`, because the output temperature is calculated as `20 + dT`. If the extractor is left at its current defaults, update its simulated-file and temperature settings to use this generated `sim_t_60.csv` file.

The coefficients used by the simulation are also defined in this script:

- `D1`: Brillouin frequency shift per degree Celsius.
- `D2`: additional Brillouin frequency shift per microstrain.
- `D3`: Rayleigh-to-Brillouin amplitude-ratio change per degree Celsius.
- `D4`: additional amplitude-ratio change per microstrain.

### Run

```powershell
python mtx_coeff_gen.py
```

The script prints the output file name, saves the simulated CSV in the current folder, and opens plots comparing the original and simulated peak values and peak-bin positions. Close the plot windows to finish the process.

### Generated CSV format

The output is a semicolon-delimited CSV with this header:

```text
Distance_m;Rayleigh_Peak_Amplitude;Brillouin_Peak_Amplitude;Rayleigh_Peak_Bin;Brillouin_Peak_Bin
```

The generated file contains only the detected peaks, not the complete original frequency matrix.

## 2. Extract coefficients

### Purpose

`mtx_coeff_extract.py` calculates the following coefficients by comparing the baseline data with the higher-temperature data:

- `D1`: Brillouin frequency shift in MHz per degree Celsius.
- `D2`: additional Brillouin frequency shift in MHz per microstrain.
- `D3`: Rayleigh-to-Brillouin percentage change per degree Celsius.
- `D4`: additional Rayleigh-to-Brillouin percentage change per microstrain.

It reports statistics for both configured segments:

- `seg_free`: `1000-1100 m`
- `seg_met`: `1500-1600 m`

### Configure validation mode

At the top of `mtx_coeff_extract.py`, select the source for the higher-temperature data:

```python
calc_check = 1
```

Use `calc_check = 1` to read a simulated peak-data file. Update `simulated_file_path` to match the file generated by `mtx_coeff_gen.py`, and keep `T1` consistent with that file:

```python
simulated_file_path = 'sim_t_40.csv'
T0 = 20
T1 = 40
```

These are the current defaults in `mtx_coeff_extract.py`. To use the output from the generator with its default `dT = 40.0`, change them to:

```python
simulated_file_path = 'sim_t_60.csv'
T0 = 20
T1 = 60
```

When `calc_check = 1` and the simulated file exists, the script uses that file instead of `t_40.csv`. If the file is missing, it prints a warning and falls back to `t_40.csv`.

Use `calc_check = 0` to compare the two original files directly:

```python
calc_check = 0
```

In this mode, the script reads `t_20.csv` and `t_40.csv`.

The analysis settings should match the generator when comparing against simulated data:

```python
spatial_resolution = 0.1
seg_free = (1000.0, 1100.0)
seg_met = (1500.0, 1600.0)
```

### Run

```powershell
python mtx_coeff_extract.py
```

The script prints:

- Mean Rayleigh amplitude for each temperature and segment.
- Mean Brillouin amplitude for each temperature and segment.
- Mean Brillouin frequency-bin position for each temperature and segment.
- Baseline and higher-temperature Rayleigh peak ratios (`RLP`).
- Baseline and higher-temperature Brillouin frequencies (`vB`) in MHz.
- Frequency and amplitude deltas.
- The calculated coefficients `D1` through `D4`.

It also opens comparison plots for:

- Peak values at the two temperatures.
- Peak-bin positions at the two temperatures.
- The calculated temperature profile along the fiber.
- The calculated strain profile along the fiber.

Close the plot windows to finish the process. The calculated profiles use matrix inversion of the four coefficients. If the coefficient determinant is zero, the script uses a constant `T0` temperature profile and a zero strain profile.

## Recommended workflow

1. Place `t_20.csv` and, if needed, `t_40.csv` in this folder.
2. Edit and run `mtx_coeff_gen.py` when a simulated higher-temperature dataset is required.
3. Confirm that the generated file name matches `simulated_file_path` in `mtx_coeff_extract.py`.
4. Set `T1` to the simulated output temperature, then run `mtx_coeff_extract.py` with `calc_check = 1`.
5. For a comparison using the original measurements, set `calc_check = 0` and run `mtx_coeff_extract.py`.

## Troubleshooting

### File not found

Run the command from the folder containing the scripts and CSV files, or replace the relative paths with absolute paths in the scripts.

### Simulated file is not used

Check that `calc_check == 1`, that `simulated_file_path` has the correct name, and that the file exists in the current folder. Otherwise, the extraction script falls back to `t_40.csv`.

### Empty or invalid segment results

Confirm that the input contains enough spatial samples to reach `1500-1600 m` and that the configured `spatial_resolution` matches the data. Also verify that the CSV contains numeric semicolon-delimited rows after any metadata lines.

### Plots do not appear or Python reports missing modules

Install the required packages and use a Python environment with graphical Matplotlib support:

```powershell
python -m pip install numpy matplotlib
```
